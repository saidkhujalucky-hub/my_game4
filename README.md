# HERO TYCOON — играть сразу через GitHub Pages

**В этой версии игра действительно запускается при открытии GitHub Pages.** Не нужны Node.js, npm, `server.js`, WebSocket, сервер, регистрация или внешние CDN.

## Установка за 1 минуту
1. Распакуйте архив.
2. Загрузите **все файлы из архива** в **корень репозитория** GitHub: `index.html`, `game.js`, `style.css`, `.nojekyll` (README по желанию). **Не загружайте их во вложенную папку `public`!**
3. Откройте Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Откройте ваш адрес вида `https://USERNAME.github.io/REPO/`.

## Что работает
- Настоящий 3D-мир на WebGL с 12 базами, генераторами, деревьями, башнями, 12 героями и движущимися NPC.
- Боты, бои, способность героя, рейды на базы, улучшения, получение монет, миникарта.
- Поддержка ПК и сенсорных экранов; сохранение прогресса через `localStorage`.
- Всё без внешних библиотек и серверов. Может работать даже без интернета после сохранения файлов на устройстве.

## Управление
- `WASD` или стрелки: ходьба
- Двигайте мышью с зажатой левой кнопкой: повернуть камеру
- `Пробел`: атака · `Q`: суперсила · `E`: улучшить базу
- `Esc`: пауза
- На телефоне: виртуальный джойстик и кнопки

## Важно про онлайн
GitHub Pages — статический хостинг. **Настоящей сетевой игры с 12 людьми здесь нет:** остальные 11 героев — боты. Для реального мультиплеера понадобится отдельный WebSocket-сервер, который нужно развернуть на сервисе, поддерживающем постоянные соединения. README не обещает онлайн-функций, которых нет.

Герои придуманы специально для этой игры; образы и названия персонажей Marvel не используются.
